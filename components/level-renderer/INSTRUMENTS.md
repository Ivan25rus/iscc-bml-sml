# Как добавить инструмент TradingView MT5 и ISCC

Для каждого инструмента задаётся точная пара: полный символ TradingView → имя инструмента MT5. После подтверждения линии индикатором цена MT5 попадает в собственную группу Level Track. Это позволяет добавлять индексы, валюты и другие доступные у брокера инструменты без изменения исходников модуля.

Переносится High или Low соответствующей **закрытой свечи MT5**, определённой по времени, периоду и стороне свечи TradingView. Цена линии TV может отличаться от результата у брокера. Произвольная горизонтальная цена не превращается автоматически в точный свечной уровень.

## 1. Подготовить связь

При выборе функций полного комплекта отметьте «Уровни TV → MT5» и, если нужны уровни в панели, «Уровни MT5 → LT». Для одних уровней BML/SML устанавливать не требуется. Уже переданный корневой план `levels-selection.json` используется без второго выбора во вложенном установщике.

Убедитесь, что штатный коннектор TradingView подключён, а нужный MT5 доступен. На терминале должен работать **один** соответствующий индикатор: `ISCC Candle Levels` для совместимого моста либо `ISCC Addon Levels` для приёмника только свечей. Оба писателя одновременно не запускайте.

Для нового инструмента откройте его график в MT5. Индикатор ищет подходящие уже открытые графики и сам их не открывает. Один экземпляр индикатора в терминале обслуживает подходящие графики; добавлять его на каждый график не нужно.

## 2. Узнать два точных имени

В TradingView возьмите полное имя с источником данных: например, `CAPITALCOM:US500`. Одного `US500` недостаточно. На другом источнике тот же индекс имеет другой полный символ — это отдельная строка привязки.

В MT5 откройте «Обзор рынка», найдите соответствующий инструмент и скопируйте его полное имя. Сохраните регистр, точки, суффиксы и префиксы: `US500`, `SPX500` и `US500.cash` — разные имена для настройки. Инструмент должен действительно существовать в выбранном терминале. Сопоставляйте одинаковый базовый актив; фьючерс и CFD с похожим названием могут иметь разные сессии и цены.

Ниже условные примеры. Имена в правом столбце заменяются именами вашего брокера.

| Полный символ TradingView | Пример точного имени MT5 | Новая группа LT |
| --- | --- | --- |
| `CAPITALCOM:US500` | `US500.cash` | `TV → MT5 · US500.cash` |
| `CAPITALCOM:NAS100` | `USTEC.cash` | `TV → MT5 · USTEC.cash` |

## 3. Добавить строку в настройках ISCC

В установленном дополнении откройте **Настройки → Отрисовщик уровней → Точные пары символов TradingView → MT5**. Добавьте строку и заполните:

| Поле | Что указать |
| --- | --- |
| Включена / `enabled` | Включить эту пару |
| Полный символ TradingView / `sourceSymbol` | Полное имя с источником данных |
| Точное имя MT5 / `mt5Symbol` | Имя из «Обзора рынка» выбранного терминала |
| ID рабочего графика / `sourceLayout` | Собственный ID раскладки, определённый агентом локально; поле необязательно |

Сохраните настройки. При уже встроенном в вашу панель переносе эти же поля могут находиться в **TV Listener → Свечные уровни ТВ → MT5 → ЛТ → Пары инструментов**. Используйте установленный вариант; второй синхронизатор поверх первого не нужен.

Для одного полного символа TV допускается только одно включённое назначение MT5. Несколько источников TV могут вести в один инструмент MT5; совпадающие подтверждённые цены объединяются. Всего допускается до 32 строк.

Если агент редактирует локальную конфигурацию, строка массива `mappings` выглядит так:

```json
{
  "enabled": true,
  "sourceSymbol": "CAPITALCOM:US500",
  "mt5Symbol": "US500.cash"
}
```

Это **одна новая строка**, а не замена всего файла настроек. Остальные пары, способ подключения и настройки пользователя сохраняются. В дополнении массив находится в `candle-renderer`; у встроенного варианта — в `tv-listener.candleLevels`.

`sourceLayout` помогает определить рабочую раскладку и подтвердить пропущенное удаление после перезапуска. ID агент получает из вашей раскладки. В поле указывается ID, а не полная ссылка. Не копируйте ID из чужого примера. Пустое поле допустимо; отсутствие неизвестной линии само по себе не считается разрешением на её удаление.

## 4. Проверить линию в MT5

Включите отрисовщик после настройки пары и подключения. В TV откройте указанный символ, выберите закрытую свечу и поставьте поддерживаемую горизонтальную линию или луч на её High либо Low. Сохраните разметку.

Дождитесь чтения исходной свечи, расчёта по истории MT5 и подтверждения индикатора. Проверьте **саму видимую линию и цену на шкале** открытого графика MT5. `ready` подтверждает обработку объекта; масштаб и положение видимого графика проверяются отдельно.

При изменении свечи, её стороны или цвета обновляется та же связанная отметка. Белая отметка TV показывается красной в MT5; красные `#F23645` и `#FF0000` — фиолетовыми. Цвет не выбирает период или цену свечи.

Сравните одну известную закрытую свечу по времени и High/Low. Часы TV, компьютера и исторических баров брокера — разные источники времени. Для каждого вновь подключённого терминала проверяются собственные исторические часы. Текущее расхождение не исправляют случайным сдвигом времени компьютера. Приёмник поддерживает проверенное фиксированное смещение либо явно настроенную модель New York + N часов; порядок приведён в [INSTALL.md](INSTALL.md). Окно со сменой смещения не подменяется соседней свечой.

## 5. Получить уровень в LT

В дополнении включите **Передавать подтверждённые цены в ЛТ / `publishToLT`**. В полном комплекте для этого должна быть выбрана функция `levels-to-lt`; у встроенного переноса используйте его штатный режим публикации. После подтверждения MT5 появляется группа **`TV → MT5 · <точное имя MT5>`** с этим же тикером. Если такое имя группы уже занято вручную, дополнение добавляет номер к названию и сохраняет ручную группу.

Третьей пары «TV → ISCC» нет: тикер автоматической группы LT берётся из `mt5Symbol`. Проверьте его совпадение с инструментом, который использует ваша панель. Если карточка или брокерский адаптер работает под другим тикером, агент отдельно согласует штатное соответствие инструментов; переименование отображаемой группы этого не исправляет.

Включение уровней в LT может задействовать уже настроенные торговые правила. Проверяйте перенос при остановленных автоматических входах; саму сделку для проверки открывать не нужно. Разрешения читать свечи, переносить уровень и торговать инструментом настраиваются отдельно. Привязка для уровней не добавляет новый инструмент в торговый список BML/SML.

Незапущенная карточка может получить обновлённый LT. Уже принятый набор сохраняет исходный уровень. Ручные объекты MT5 и ручные группы LT сохраняются.

## 6. Проверить обновление и удаление

Измените отметку в TV и дождитесь обновления связанного объекта MT5 и цены LT. Затем удалите тестовую отметку в TV. После подтверждения MT5 её цена удаляется из автоматической группы, если другой подтверждённой отметки на той же цене нет.

При перезапуске пропущенные удаления проверяются по двум полным свежим сверкам известных раскладок. Закрытый график, загрузка TV, незавершённое сохранение и отсутствие достоверных данных не означают удаление. Ручные объекты не участвуют в этой очистке.

## Если уровень не появился

| Где остановилось | Что проверить |
| --- | --- |
| Не видна отметка TV | Полный символ, рабочую раскладку, сохранение линии, штатное подключение TV |
| Ожидание исходной свечи | Закрыта ли свеча, доступны ли её точные границы и история TV |
| MT5 не знает символ | Точное имя, суффикс, наличие в «Обзоре рынка» нужного терминала |
| Ожидание истории MT5 | Историю нужного символа и периода, историческую модель часов брокера |
| Ожидание индикатора | Подходящий открытый график, выбранный индикатор и соответствие файлов его режиму |
| В MT5 линия есть, в LT нет | `levels-to-lt`, `publishToLT`, подтверждение MT5, тикер автоматической группы |
| Удаление не подтверждается | Доступность рабочей раскладки, `sourceLayout`, завершённое сохранение и свежие сверки |

Добавляйте следующие инструменты тем же порядком: новая строка → открытый график MT5 → одна проверенная свеча → подтверждённая цена LT.
