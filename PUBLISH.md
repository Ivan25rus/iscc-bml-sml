# Публикация комплекта

Проверьте `python3 prepare.py --verify`, запустите JavaScript- и Python-тесты. Публикуются только файлы этого комплекта, перечисленные в manifest.json. ignored `local/` с настройками и материалами сравнения не загружается.

Комплект BML/SML размещается отдельно от отрисовщика уровней. README описывает реализованные функции и интеграцию с совместимым MT5-адаптером.

Для нового репозитория используйте корневую папку распакованного комплекта. Загрузите содержимое, включая ci, .gitignore и manifest.json. Архив можно приложить к выпуску отдельно. Перед загрузкой повторите prepare.py --verify: посторонний файл вне ignored local/ считается ошибкой.

Для предложения автору создайте отдельную ветку и PR с узкими изменениями исходного проекта после адаптации. Не включайте BML/SML в PR отрисовщика уровней. Не заявляйте готовую установку или проверку реального брокера только по результатам фиктивного терминала.
