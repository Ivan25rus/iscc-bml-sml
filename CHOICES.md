# Выбор функций перед установкой

Откройте SETUP.html локально после распаковки всего архива. Можно выбрать все функции, только BML/SML, только уровни или собственное сочетание. Передайте сохранённый план и папку Claude Code или Codex. Если агент получил только ссылку, он сначала показывает этот список и получает выбор, затем выполняет установку. Наличие файлов в архиве не означает разрешение установить все интерфейсы.

| Выбор | Что обязательно добавляется | Что можно оставить выключенным |
| --- | --- | --- |
| BML/SML | Процент частей, рынок и лимитка, общий SL, резервирование неизвестного объёма, отмена, сверка, восстановление, остановка | Дополнительные счета, отдельное окно управления и автоматическое закрытие |
| Несколько счетов | Общее ядро MT5 и проверка отдельных терминалов | BML/SML и окно управления |
| Управление | Проверки принадлежности, SL/TP, стоп во вход, полное закрытие и отмена | Частичное закрытие и новые ценовые условия |
| Частичное закрытие | Управление позициями и проверка объёма/остатка | Новые ценовые условия |
| Закрытие части по цене | Частичное закрытие и управление | BML/SML, дополнительные счета и закрытие по времени |
| Закрытие по времени | Общее ядро MT5 и раздел настройки срока | BML/SML, управление и дополнительные счета |
| TradingView → MT5 | Отрисовщик 0.1.4, один подходящий индикатор 1.17, приёмник свечей или совместимый существующий мост | Передача в LT и все торговые дополнения |
| MT5 → LT в ISCC | Перенос TradingView → MT5 и подтверждение индикатором | Все торговые дополнения |

Процент входа, денежный расчёт, лимитная поддержка, общий стоп и проверки не разбиваются на отдельные галочки: это одна логика BML/SML. Множитель счёта меняет лот, а не вычисляет долю автоматически по балансу. У BML/SML частичное закрытие относится к выбранной части выбранного счёта.

Общие исходники исполнителя могут содержать больше возможностей, чем выбрано. Они остаются целыми ради совместимости. Галочки задают доступность новых интерфейсов и команд дополнения, а не удаляют части ядра. module/featurePolicy.js применяется только к новым маршрутам дополнения; существующие маршруты панели не перехватываются. Для полного закрытия обычной позиции проверяется весь её фактический объём.

Выбор не является удалением ранее установленных функций. Существующие копируемые счета, открытые наборы, SL/TP и сохранённые ценовые/временные условия не отключаются и не очищаются. Их просмотр, отмена, остановка и сверка сохраняются. Отсутствие галочки не должно менять текущую конфигурацию получателя. Для нового подключения всё изначально выключено, списки счетов и пар символов пусты.

Подготовка проверяет хеши, разрешает зависимости и выдаёт review.json, feature-policy.json и, при выборе уровней, levels-selection.json. Для интерфейса копируется полная цепочка импортов выбранных модулей. Для одних уровней торговые исходники не подготавливаются. При уже установленной функции агент сравнивает версии и объединяет её, сохраняя один активный координатор и один синхронизатор уровней.
