# Состав доработок

| Возможность | Что передаётся |
| --- | --- |
| LT и люфт | Сохранённый уровень и односторонний диапазон BML/SML; обычные LB/LS сохраняются. |
| Процент частей | Настройка общая и по инструменту, дробные проценты, 100%, ограничения лота брокера. |
| Первоначальный расчёт | Общий лот из риска и стопа; последний контракт набирает фиксированный лот без постоянного денежного ограничения. |
| Рынок + лимитка | Лимитка на свободный остаток, лимитка у внешней границы, учёт исполнений при отмене. |
| Общий стоп | Средневзвешенный вход либо SL от LT; точные позиции каждого набора и счёта. |
| Дополнительные MT5 | Обнаружение, регистрация отдельного терминала, включение копирования и коэффициенты лота. |
| Независимые счета | Собственные журналы, независимые подтверждения и добор только допустимого остатка. |
| Ожидание цены | MT5 проверяет свежесть; принятый план ждёт свежий тик и продолжает автоматически. |
| Потерянный ответ | Сверка квитанций и истории; неизвестный объём не отправляется повторно. |
| Остановка | Отзыв разрешения на добор, отмена лимиток, сохранение открытых частей и SL. |
| Карточки | Объёмы по счетам, восстановление набора, возврат к входу после подтверждённого полного выхода. |
| Управление | Общий SL/TP, стоп во вход, полное закрытие точного набора. |
| Частичное закрытие | Лоты или процент выбранной позиции; условие по цене; показ объёма и остатка до отправки. |
| Скорость и диагностика | Приём плана одним запросом, меньше повторных чтений, события состояния, время операций и причины ожидания. |
| Закрытие по времени | Настройка срока новых сделок и исполнение сохранённого правила без панели. |
| TV → MT5 | High/Low закрытой свечи, цвет, изменение, удаление и подтверждение индикатором 1.17. |
| MT5 → LT в ISCC | Передача подтверждённой цены с сохранением ручных групп LT. |
| Выбор перед установкой | Восемь функций, готовые наборы и зависимости; правила в CHOICES.md. |

Процент входа — доля первоначального лота. Процент закрытия — доля фактической выбранной позиции. Коэффициент счёта — множитель лота основного; он не зависит автоматически от баланса.

Для BML/SML частичное закрытие выбирает конкретную часть на конкретном счёте. Групповые SL/TP и полное закрытие используют родительский набор. Старые сохранённые планы не переводятся автоматически на новый алгоритм.

Срок набора ограничен правилом закрытия по времени: оно может закрыть остаток позиции и без открытой панели. До 16 дополнительных счетов предусмотрено программно; производительность такого числа терминалов проверяется получателем. В новом режиме действуют пределы 100 рыночных частей и 512 отправок на счёт.

Комплект интегрирует перечисленные функции с существующей ISCC и совместимым исполнителем MT5. Принимающая среда и сборка проверяются отдельно.
