# Проверки ISCC

## 0.4.1

Тесты запускались из распакованного комплекта на имитации MT5 и временных локальных соединениях.

| Набор проверок | Успешно |
| --- | ---: |
| Основной JavaScript | 189 |
| Основной Python | 579 |
| JavaScript отрисовщика | 78 |
| Python отрисовщика | 84 |
| Всего | 930 |

Все 930 тестов прошли без ошибок и пропусков.

Для полного закрытия проверки охватывают совместную сверку счёта и позиции, точный объём по тикету и независимое закрытие на связанных счетах. В сценариях с запаздывающим состоянием MT5 моделируются устаревший список позиций и задержка записи в историю. Проверяется подтверждение по истории без повторной отправки и сохранение неопределённого статуса, пока подтверждения нет.

В интерфейсе проверяются статус по счетам и автоматическое чтение состояния конкретного набора. Для лимитки на возврате моделируется промежуток между исчезновением заявки и появлением позиции. Замеры исполнения на реальном счёте зависят от подключения получателя.

## 0.4.0

Комплект проверен как исходники для интеграции с панелью. Проверки выполнялись на имитации MT5 и временных локальных HTTP-соединениях, без обращения к установленным торговым терминалам.

| Набор проверок | Успешно |
| --- | ---: |
| Основной JavaScript | 165 |
| Основной Python | 527 |
| JavaScript отрисовщика | 78 |
| Python отрисовщика | 84 |
| Всего | 854 |

Ошибок и пропусков нет. Отдельно прошли 5 проверок границ экспорта и 6 проверок статических изображений. Проверены все 255 непустых сочетаний восьми функций, соответствие выбора Python и JavaScript, цепочки импортов, manifest и сохранение исходников получателя при подготовке.

Проверены независимый набор фиксированного объёма, общий SL, риск от текущего баланса, стоп от входа и от LT, смешанные режимы связанных счетов, сохранение принятого расчёта при повторе и восстановлении. Частичное закрытие и частичный тейк проверены по всему остатку точного набора на каждом связанном счёте, включая округление, допустимый остаток, неизвестный ответ и перезапуск.

Новые проверки обработки задержек подтверждают отдельный канал ожидания событий, немедленную публикацию завершённого чтения и сохранение всех счетов при быстром завершении. Повторное использование котировки ограничено 100 мс, возвращает отдельную копию и сохраняет исходное время. Устаревший, ошибочный, отсутствующий или закрытый кадр требует обычного свежего чтения. Торговые проверки этими изменениями не отключаются. Постоянная максимальная задержка доставки этим тестом не подтверждается.

Инструкция SPX содержит 16 снимков интерфейса с учебными позициями и счетами A/B/C. Графики управления используют сохранённые M1 MT5. Отображение состояний и расчёты проверены отдельно; снимки не являются записью реальных брокерских исполнений.

После объединения агент выполняет проверки принимающей панели, сборку, установку и проверку загруженных модулей и соединений по [AGENT_INSTALL.md](AGENT_INSTALL.md). Время исторических баров, компиляция индикатора, видимость линии и соответствие тикера LT проверяются на компьютере получателя по [INSTRUMENTS.md](components/level-renderer/INSTRUMENTS.md). Для новой установки или нового терминала эти этапы обязательны. Результат сохраняется в локальном отчёте установки.
