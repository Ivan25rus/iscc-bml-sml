Выбери дополнения для ISCC

Набор BML/SML и Level Track: TradingView → MT5 → ISCC. Комплект 0.3.0 для установки через Claude Code или Codex.

Быстрый выбор

Какие функции установить

Нужные зависимости добавятся автоматически. Стоп, проверка объёма, подтверждение отмены, сверка исполнения и восстановление входят в BML/SML целиком.

Существующие функции ISCC и сохранённые правила остаются доступны. Снятие галочки определяет состав нового дополнения и не отменяет действующие сделки или условия.

Где подготовить установку Для одних уровней используется приёмник свечей или существующий мост. Торговое ядро для них не добавляется.

План для агента

Передай агенту распакованную папку и план. Он проверит текущую ISCC, объединит выбранные изменения, выполнит тесты и сборку. Подготовка оставляет торговлю выключенной.
