# Установка дополнения

1. Откройте SETUP.html, выберите компоненты и сохраните JSON в `local/selection.json`. План готов сразу: вопросов о версии и своих доработках нет. Приёмник по умолчанию определяется автоматически. Учётные данные и адреса в меню не нужны.
2. Агент определяет локальный путь установленной панели. Если есть только `.app`/`.exe`, он извлекает исходники в рабочий проект, добавляет модуль и собирает приложение. Внешние настройки остаются на своих местах. Копии прежней программы и настроек не создаются. Если панели ещё нет, сначала установите базу автора: https://github.com/iziziz-indepstate/indepstate-cc .
3. Для проекта исходников выполните (на Windows допустимо `py -3` вместо `python3`):

```sh
python3 install.py install --source /path/to/iscc-project --plan local/selection.json
```

Команда проверяет совместимость и устанавливает дополнение без повторного подтверждения и резервной копии. Рабочие файлы появляются в автоматически созданной папке под `local/`. При несовпадении точки интеграции или уже установленном отрисовщике установка останавливается до изменения исходников.

4. Для диагностики доступны раздельные подготовка и применение:

```sh
python3 install.py stage --source /path/to/iscc-project --plan local/selection.json --work local/prepared
python3 install.py apply --work local/prepared
```

Отдельное согласование не требуется. `changes.patch` и `review.json` содержат техническое сравнение и контрольные суммы; старые файлы целиком не сохраняются. Эти частные материалы не публикуются. Проверка хешей защищает от замены файлов, изменённых между подготовкой и применением. При ошибке записи в том же процессе уже записанные файлы восстанавливаются из памяти; автоматического отката после установки нет.

5. Установите зависимости выбранной сборки. Установщик добавляет прямую зависимость `ws` в package.json, когда её нет; агент обновляет соответствующий lockfile штатным менеджером пакетов и собирает приложение для нужной ОС. Не запускайте авторскую команду `release`: она публикует сборку.
6. Выберите **один** подходящий индикатор. Скопируйте `.mq5` в `MQL5/Indicators`, скомпилируйте MetaEditor и оставьте на одном графике терминала. Режим `iscc` использует обычный индикатор; режим `stdio` — Addon. Исходный индикатор не заменяется.
7. В настройках ИСКК появится «Отрисовщик уровней». Он изначально выключен, пары символов пустые. Введите точное полное имя TradingView и точное имя MT5. Настройте штатный коннектор TradingView и локальный отладчик на порту 9222; функция не запускает браузер и не меняет системный прокси.

Для `stdio`: установите зависимости `receiver/requirements.txt` в окружении Windows рядом с MT5. Скопируйте `config.example.json` в частную папку `local/`, заполните свой путь терминала, ожидаемый каталог данных и проверенную модель исторических часов брокера. Пароль и номер счёта в конфиге не нужны: приёмник использует уже подключённый терминал и проверяет неизменность его сеанса. `initialize()` может запустить выбранный терминал с его сохранёнными настройками; отдельного входа по паролю код не выполняет. Документация MetaQuotes: https://www.mql5.com/en/docs/python_metatrader5/mt5initialize_py .

В `readerCommand` задайте массив: программа Python, путь к `receiver/read_only.py`, `--config`, путь к частному конфигу. Каждый аргумент — отдельная строка. Для удалённого MT5 агент настраивает ваш защищённый запуск; публичный пакет не содержит адресов, ключей и готовой команды SSH. Приёмник пишет в `iscc-addon-levels.csv`, индикатор — в `iscc-addon-levels-ack.csv`, объекты имеют префикс `ISCC_ADDON_TV_`. Они отделены от файлов и объектов обычного моста ИСКК.

При фиксированном смещении укажите `brokerClockModel: fixed-offset` и точные `brokerUtcOffsetSeconds`. Для подтверждённого календаря New York + N часов — `new-york-plus-hours`, `brokerClockHours: N` и пакет tzdata. Не угадывайте модель или историческое смещение по текущим часам/цвету линии. Окно через смену часов отклоняется.

8. С выключенной автоторговлей проверьте одну закрытую свечу: High, Low, перенос, смену цвета, удаление и перезапуск. Сверьте видимую линию и цену на шкале MT5. Статус ready подтверждает свойства объекта, но не его видимость при конкретном масштабе. Проверьте, что ручные объекты и группы ЛТ сохранены. Включение передачи цен в ЛТ может влиять на ранее настроенные пользователем торговые правила — включайте её после проверки этих правил.
