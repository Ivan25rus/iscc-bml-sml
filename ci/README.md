# Автоматические проверки

check.yml.example — готовый сценарий GitHub Actions для Linux и Windows. В обычной публикации он хранится как шаблон и сам не запускается.

Для включения скопируйте его в .github/workflows/check.yml в своём репозитории. Сценарий проверяет manifest, JavaScript-тесты и Python-тесты с имитацией MT5. Для тестов используются временные локальные HTTP-порты; установленный торговый терминал не запускается.

После включения добавьте новый путь в manifest.json и пересчитайте размеры/контрольные суммы изменённых файлов. Если шаблон удаляется из ci/, удалите и его прежнюю запись. Репозиторий без включённого Actions проверяется локальными командами из README.
