# Отрисовщик уровней — дополнение к ИСКК

Отдельный модуль TradingView → MT5 → ЛТ. Добавляет перенос High/Low выбранной закрытой свечи, цвет, обновление, удаление и подтверждение отрисовки. Панель автора и остальные улучшения в пакет не входят.

[Репозиторий GitHub](https://github.com/Ivan25rus/iscc-level-renderer) · [Скачать исходники ZIP](https://github.com/Ivan25rus/iscc-level-renderer/archive/refs/heads/main.zip). Распакуйте архив и откройте SETUP.html локально.

Откройте **SETUP.html**, выберите нужные компоненты и скачайте готовый план. Передайте его Codex или Claude вместе с этой папкой и инструкцией **AGENTS.md**. Версию панели и свои доработки указывать не нужно; совместимость проверяется автоматически. Резервные копии не создаются, повторного подтверждения установки нет.

Сохраняются исходные время, таймфрейм и сторона свечи; соседняя свеча не подставляется. Opening range переносится через High/Low соответствующей свечи MT5, произвольная цена TradingView не используется. В MT5 рисуется полная горизонтальная линия со штатной ценой на шкале. Белый цвет TradingView отображается красным в MT5, красные `#F23645` и `#FF0000` — фиолетовым `#673AB7`. Цвет не меняет период, сторону или цену свечи. Ручные объекты MT5 и группы ЛТ не принадлежат дополнению. Совпадающие цены в ЛТ объединяются; цена сохраняется, пока есть хотя бы одна подтверждённая отметка.

Версия дополнения **0.1.4**, индикатор **1.17**. Уровни рисуются только на уже открытых графиках подходящего символа. Закрытый график не открывается автоматически; до его открытия подтверждение остаётся в ожидании. Неизменившиеся уровни проверяются без повторной записи свойств и принудительной перерисовки. Изменённые уровни перерисовываются одним пакетом на график.

Начиная с 1.16 фактические свойства неизменных объектов проверяются раз в две секунды. Изменение снимка, символа, периода или состава графиков проверяется сразу. Полный поиск лишних собственных объектов выполняется при изменениях и каждые 30 секунд. Пропущенный такт не продлевает подтверждение: ACK обновляется только после проверки и по-прежнему истекает через пять секунд. Ошибки проверки, очистки или записи подтверждения повторяются на следующем такте. Котировки и торговые обработчики сохраняют свой режим работы. Тест сравнивает обращения к объектам с исходным индикатором 1.15; замер CPU настоящего терминала этим тестом не выполняется.

В 1.17 неизменные строки снимка повторно используются только на пропущенном такте, который не продлевает ACK. Перед каждым подтверждением индикатор читает и проверяет весь актуальный файл. Приёмник подготавливает один снимок состояния вместо двух. Тесты сравнивают чтение строк с 1.16 и проверяют повреждённые файлы, очистку кэша, смену графиков и неизменность частоты ACK.

Удаление передаётся событием работающего коннектора. После перезапуска пропущенное удаление также восстанавливается по двум полным свежим проверкам известных исходных раскладок TradingView. Неизвестная раскладка, загрузка, незавершённое сохранение, закрытый график, устаревшее чтение или отсутствие подтверждённого происхождения не считаются доказательством удаления. После ручного изменения действует защитная пауза; завершение удаления по-прежнему требует подтверждения MT5. Для определения High/Low и границ свечи её исходный период и дата должны быть загружены в TradingView; чтение не переключает график и не подгружает историю за пользователя.

Выбор получателя:

- **Существующий мост ИСКК** — если он поддерживает candle-levels, candle-levels-window и candle-levels-color. Используется индикатор `mt5/ISCC Candle Levels.mq5`.
- **Приёмник только свечей** — для обычной авторской панели без такого моста. Python рядом с MT5, обмен через stdin/stdout, отдельные файлы и объекты индикатора `mt5/ISCC Addon Levels.mq5`. VPS не нужен при работе ИСКК и MT5 на одном Windows-компьютере.
- **Передача в ЛТ** — необязательна; отключение оставляет отрисовку MT5.

Рабочие настройки исходной панели, счета, ключи и торговые модули не переносятся в это дополнение. Пары символов и команды получатель заполняет локально. В публичном пакете нет настроенного подключения.

Установщик автоматически проверяет точки подключения и применяет изменения к исходному проекту с `app/` или `src/app/`. Независимые доработки сохраняются в коде. При конфликте или уже установленном отрисовщике установка останавливается. Для готового `.app`/`.exe` агент извлекает исходники в рабочий проект и собирает приложение с дополнением. Внешние настройки сохраняются на своих местах. Резервная копия прежней программы и автоматический откат после установки не предусмотрены.

Windows: приёмник Python запускается рядом с MT5. Mac: модуль ИСКК работает на Mac; приёмник требует совместимого окружения MT5 (Windows-компьютер/виртуальная машина или уже настроенный мост). Связку локального MT5 Wine и Python на Mac этот пакет не подтверждает. Для удалённого Python используйте собственный защищённый канал запуска, например SSH, в локальной настройке `readerCommand`.

Проверки исходников и установки запускаются офлайн: `python3 -m unittest discover -s tests -p 'test_*.py'` и `node --test tests/*.test.js`. Реальная отрисовка, часы брокера, сборка Electron и MT5 проверяются отдельно на компьютере получателя.
