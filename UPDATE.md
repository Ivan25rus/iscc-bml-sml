# Обновление ISCC до комплекта 0.4.0

Выпуск 0.4.0 обновляет комплект 0.3.0: управление точным набором BML/SML, процентный выход по всем его частям, отдельный частичный тейк, риск от баланса дополнительного счёта и восстановление уровней TV → MT5 → LT. Это исходники для объединения с установленной панелью. Обновляются только выбранные функции.

## Что изменилось

| Область | Изменение |
| --- | --- |
| Управление позицией | T\|S открывает точный набор с M1-графиком MT5; SL/TP можно перетаскивать и сохранять. Доступны стоп во вход и снятие обычного TP |
| Частичное закрытие | Процент относится ко всему текущему остатку BML/SML на каждом связанном счёте. Показаны округлённые лоты и остатки; чужие позиции исключаются |
| Частичный тейк | Условие «цена + доля остатка» хранится у исполнителя и работает при закрытой панели. Обычные SL/TP сохраняются; неизвестная отправка не повторяется |
| Объём связанных счетов | Множитель лота либо собственный риск в процентах текущего баланса. Стоп от входа и от LT; расчёт принятого набора сохраняется при повторе и восстановлении |
| Связь и отображение | Ожидание событий выделено в отдельное соединение; завершённое чтение состояния становится доступно сразу. Свежий кадр котировок до 100 мс повторно используется без обновления его исходного времени |
| Уровни | Отрисовщик 0.2.0 и индикатор 1.17; независимая сверка инструментов, явное удаление рабочего графика и восстановление пропущенных удалений |
| Установка | Полный порядок для агента, выбор восьми функций, инструкция добавления инструментов и проверка после установки |

Процент части BML/SML, процент закрытия и процент риска — разные настройки. Правила независимого набора фиксированного целевого лота и его обязательные проверки сохраняются. Оптимизация чтения не является обещанием постоянной задержки или цены исполнения.

## Получить комплект и выбрать функции

1. Скачайте `ISCC-Addons-0.4.0.zip` из [выпуска GitHub](https://github.com/Ivan25rus/iscc-bml-sml/releases/tag/v0.4.0) и распакуйте целиком.
2. Откройте `SETUP.html`, выберите новые функции и сохраните план. Если плана нет, агент сначала предлагает восемь пунктов; выбор «всё» уже достаточен.
3. Передайте папку и план Claude Code или Codex. Готовое задание — [START_FOR_AGENT.txt](START_FOR_AGENT.txt), полный порядок — [AGENT_INSTALL.md](AGENT_INSTALL.md).

Выбор определяет новые дополнения. Он не отключает существующие функции, счета или правила. Для одних уровней торговый исполнитель не подготавливается.

## Обновить существующую установку

Агент определяет установленную версию и соответствующие исходники, читает локальные инструкции и сравнивает уже внесённые доработки. Если работа в другом чате пересекается с обновлением, сначала дожидается её завершения.

Из корня комплекта:

```sh
python3 prepare.py --verify
python3 prepare.py --source /path/to/iscc-project --plan local/selection.json
```

На Windows допустимо `py -3`. Пути в примерах заменяются путями вашей среды. `prepare.py` подготавливает изменения для сравнения; это ещё не установка приложения. Его материалы `reference/` не заменяют целиком `main.js`, `renderer.js` или манифест панели.

Объедините выбранные изменения, проверьте зависимости и фактические возможности исполнителя по [INTEGRATION.md](INTEGRATION.md). Для новых частичного выхода, тейка и риска от баланса требуются соответствующие возможности из `AGENT_INSTALL.md`. Не включайте новый интерфейс поверх несовместимого старого исполнителя.

При установленных уровнях сравните существующий отрисовщик с `components/level-renderer`: его установщик останавливает повторный монтаж. Объедините отличия, сохранив один писатель уровней и один подходящий индикатор на терминал. Для новой установки используйте уже подготовленный `levels-selection.json`, без второго выбора компонентов.

После объединения выполните проверки комплекта и выбранных уровней:

```sh
npm test
python3 -m unittest discover -s tests -p 'test_*.py'
```

Те же две команды выполните в `components/level-renderer`, если выбраны уровни. Затем выполните значимые проверки и штатную сборку принимающей панели. Установите её штатным способом с предусмотренным в проекте восстановлением. Не используйте `release` вместо команды сборки. Блокировку установки из-за активных наборов или заявок не обходите.

## Проверить результат

Проверьте загруженную версию и модули, связь с нужными MT5, Bid/Ask, исходное время котировки и исторических баров. Поддерживаемый режим `--mt5-maintenance verify-loaded` проверяет связь только чтением. Для проверки интерфейса и уровней реальные сделки не нужны.

На новом терминале заново проверьте его модель исторических часов и одну известную свечу. Добавление счёта не доказывает совпадение исторического времени с другим терминалом. Для уровней выполните [порядок добавления инструмента](components/level-renderer/INSTRUMENTS.md), включая видимую линию и автоматическую группу LT.

Запишите результат в `local/install-report.json`: версии, выбор, проверенные хеши, сборка, установка, связь и оставшиеся ограничения. Обновление конкретного получателя считается завершённым после его собственных проверок. [Публикация исходников и архива](PUBLISH.md) выполняется отдельно от установки.
